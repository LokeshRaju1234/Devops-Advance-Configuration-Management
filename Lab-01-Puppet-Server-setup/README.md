# Lab 01 — Puppet Server Setup

## Objective

To install, configure, and verify a Puppet Server on Ubuntu Linux.

## Environment

| Component              | Details            |
| ---------------------- | ------------------ |
| Operating System       | Ubuntu 24.04.4 LTS |
| Codename               | noble              |
| Architecture           | amd64              |
| Puppet Version         | 8.21.0             |
| Hostname               | `loki223`          |
| Puppet Server Certname | `loki223.lpu.com`  |
| Puppet Server Port     | `8140`             |

## What This Lab Covers

* Puppet Server installation
* Puppet Server service
* Linux hostname
* Puppet certname
* Puppet Server network port
* Puppet Server HTTPS API
* `/etc/hosts` hostname resolution
* Puppet server configuration
* Puppet Certificate Authority (CA)
* Puppet certificates
* Automatic startup of Puppet Server

## Lab Result

Puppet Server was successfully installed, configured, and verified on Ubuntu.
